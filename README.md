for MS Sql please change the data type TINYINT(1) into BIT data type
Specifying a display width or size limit in parentheses—like TINYINT(1) or INT(11)—is a feature used in MySQL, but MSSQL does not allow size parameters for integer types. In MSSQL, a TINYINT is always exactly 1 byte (storing whole numbers from 0 to 255).
